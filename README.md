# LearnQuest v3.0 — Gamified iOS Learning Application (Studio White, Jet Black, Slate Gray & Amber Yellow Theme)

LearnQuest is an interactive, gamified iOS educational application built with **Swift 5** and **UIKit** following the **MVVM (Model-View-ViewModel)** architecture.

## Visual Palette (Matched to Reference Image)
- **Pure White Canvas (`#FFFFFF`)** & **Soft Studio Gray Cards (`#F5F5F7`)**
- **Jet Black (`#111113`)**: Primary headlines, squircle icon badges, chapter pills, and primary buttons
- **Studio Amber Yellow (`#F5C43E`)**: Accent squircle badges, XP pills, progress bars, segmented controls, and unlocked achievement badges
- **Slate Gray (`#86868B`)**: Secondary headlines, kickers, and metadata labels
